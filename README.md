# LocalBite Food Delivery App

A fully local food delivery platform prototype with:

- Local menu content stored in `data/menu.json`
- Pricing details for each dish
- Local image assets (SVG) for every item
- Search + cuisine filter
- Cart with subtotal, delivery fee, and total
- Responsive UI

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
